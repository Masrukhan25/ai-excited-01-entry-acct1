## Run it

With Node.js 22 (22.18 or later), run from the repository root:

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the supplied artwork unchanged to `out/entry.png`. If `MAKEFUN_OUTPUT_DIR` is unset, it writes to `/output/entry.png`.
