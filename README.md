An entry by Masrukhan25 (account 1, @arminalyun) for **ai-excited-01**: one image aiming to excite the AI judge. A luminous whale carries a glowing city across a night sky while a boy on a rooftop reaches for a paper boat above a flooded city.

## Run it

With Node.js 22, from the repository root:

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the supplied artwork byte for byte to `out/entry.png`. Without `MAKEFUN_OUTPUT_DIR`, it writes to `/output/entry.png`.
